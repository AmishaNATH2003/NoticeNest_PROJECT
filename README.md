# NoticeNest — Smart Deadline Manager

## What is NoticeNest?

NoticeNest is a task and deadline management project that I am developing using Java. The current version is a simple console-based application that allows users to record their daily goal, add tasks, and view their task list in one place.

The main idea behind NoticeNest is to help people organize their daily activities and keep track of the tasks they need to complete.

## Why Am I Building NoticeNest?

In our daily lives, we often have multiple tasks, goals, and deadlines to remember. Sometimes, it becomes difficult to keep track of everything.

NoticeNest aims to address this problem by providing a simple place to record daily goals and tasks. Instead of relying only on memory, users can write down their tasks and view them whenever needed.

## How Does NoticeNest Help?

- **Organizes daily goals:** Users can enter their main goal for the day.
- **Keeps tasks in one place:** Users can add multiple tasks to a single list.
- **Makes tasks easy to review:** The application displays tasks with numbers, making the list easier to read.
- **Provides a simple interface:** A menu allows users to add tasks, view tasks, or exit the application.
- **Creates a foundation for better planning:** Future versions could include deadlines, priorities, reminders, and permanent task storage.

## How Does It Work?

1. The user enters their name.
2. The application asks for today's goal.
3. The goal is stored in a task list.
4. The user can add additional tasks.
5. The user can view all saved tasks in a numbered list.
6. The user can exit the application.

## Technologies Used

- **Programming Language:** Java
- **Data Structure:** ArrayList
- **Input Handling:** Scanner
- **Core Concepts:** Loops, switch statements, variables, strings, and conditional statements.

## Current Project Status

NoticeNest is currently in its initial development stage as a Java console application.

The current version supports adding tasks, viewing tasks, and storing today's goal during the program's execution. Tasks are stored in memory and are lost when the program closes.

Features such as deleting tasks, tracking deadlines, reminders, and permanent storage have not been implemented yet.

## Future Plans

As I continue developing NoticeNest, I plan to explore improvements such as:

- Adding due dates and priority levels.
- Improving input validation.

- Developing a more user-friendly interface.

These are future goals, and I plan to introduce them gradually as the project develops.
